# AI-LOG

## Checkpoint 1 (W1–W4): form, daftar, hapus, localStorage

- Prompt: "Saya sedang mengerjakan ETS Pemrograman Web dengan tema Personal Money Management menggunakan HTML, CSS, dan JavaScript murni. Saya memilih persona mahasiswa kos yang mendapatkan uang bulanan tetap dari orang tua dan sering kehabisan uang sebelum akhir bulan. Bantu saya mengerjakan checkpoint W1–W4 dari awal dengan kode yang sederhana dan mudah dipahami mahasiswa semester awal. W1 adalah membuat form transaksi dengan tanggal, jenis pemasukan atau pengeluaran, kategori minimal 4 pilihan, nominal, dan catatan opsional. W2 adalah menampilkan daftar transaksi secara dinamis menggunakan JavaScript, mengurutkan transaksi terbaru di atas, dan menampilkan nominal dalam format Rupiah. W3 adalah menambahkan tombol hapus dengan konfirmasi sebelum transaksi dihapus. W4 adalah menyimpan dan membaca data menggunakan localStorage dengan JSON.stringify() dan JSON.parse() agar data tidak hilang setelah halaman di-refresh. Pisahkan kode menjadi index.html, style.css, dan script.js. Setiap transaksi harus memiliki id unik dan nominal disimpan sebagai angka. Buat juga fitur khas mahasiswa kos berupa input uang bulanan dan perhitungan jatah harian berdasarkan sisa uang dan sisa hari dalam bulan berjalan. Jelaskan cara kerja kode dan pastikan ID elemen HTML sesuai dengan JavaScript."
- Dipakai: `index.html`, `style.css`, dan `script.js` untuk checkpoint 1, termasuk fungsi `muatData()`, `simpanData()`, `renderDaftar()`, penanganan form `tambahTransaksi()`, dan `hapusTransaksi()`.
- Diubah: Nama aplikasi menjadi MoneyTalks, tampilan disesuaikan dengan tema hijau gelap, kategori transaksi disesuaikan dengan kebutuhan mahasiswa kos, serta ditambahkan input uang bulanan dan tampilan jatah harian.
